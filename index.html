Abstract

IMAGGarment+ is a controllable garment generation framework built on Stable Diffusion XL. Given a silhouette sketch, logo, color hint, and spatial mask, it generates a garment image while preserving the requested structure and visual details. Its attribute-wise feature extractor uses LoRA to learn separate representations for the conditions, and its attribute-adaptive attention injects those representations into suitable layers of the denoising UNet. This design combines fine-grained control with parameter-efficient training.

The attribute-wise feature extractor encodes the sketch, logo, and color hint in parallel feature streams; the mask refines the structural input for placement control. Attribute-adaptive attention then injects silhouette features into the first decoder layer, color features into the second, and logo features across layers to maintain detail consistency.

Abstract

This paper presents IMAGGarment+, an efficient attribute-wise diffusion framework for controllable garment generation. Built on Stable Diffusion XL, it uses an attribute-wise feature encoder to represent silhouette, logo, and color hints, and attribute-adaptive attention to inject those features into the denoising UNet. The framework generates garments with fine-grained control while training a small set of additional parameters.

Method

The attribute-wise feature encoder learns separate representations for the garment conditions using LoRA. Attribute-adaptive attention then injects silhouette and hint features into the first and second decoder layers, while logo features guide detail preservation across the denoising process.
